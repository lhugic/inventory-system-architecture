# Проектирование архитектуры БД и моделирование бизнес-процессов

## О проекте
Полный цикл системного и бизнес-анализа для автоматизации процессов снабжения и учёта имущества в административно-хозяйственном отделе частного охранного предприятия.

**Цель:** убрать ручной бумажный документооборот, исключить дублирование данных и спроектировать архитектуру новой автоматизированной информационной системы (АИС).

## Стек
- BPMN, IDEF0 — моделирование процессов (AS-IS и TO-BE)
- ER-моделирование (IDEF1X) — проектирование базы данных
- BPwin, ERwin, Adobe Photoshop

## Что сделано

1. **Анализ предметной области**  
   Разобрал текущие процессы снабжения, нашёл узкие места бумажного документооборота.

2. **Модели TO-BE**  
   Спроектировал оптимизированные процессы в BPMN и BPwin. Ключевые контрольные и учётные функции переданы системе.

3. **Архитектура данных**  
   Разработал логическую структуру реляционной базы данных (заявки, остатки на складах, поставщики, документооборот).

4. **Прототипы интерфейсов**  
   Сделал ролевые макеты экранов для сотрудников АХО и руководства.
